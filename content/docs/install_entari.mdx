[Entari](https://arclet.top/tutorial/entari) 是基于 Python 的跨平台聊天机器人框架，使用 Satori 协议（类似 Koishi），偏向于有基础的开发者。

本教程以 [`astral-uv`](https://docs.astral.sh/uv/) 为例，介绍从零开始安装 Entari 并对接 LLBot 的完整流程。

## 安装 Python

在 [uv 安装教程](https://docs.astral.sh/uv/getting-started/installation) 中选择适合你系统的安装方式即可。

以 Linux 为例，安装 uv：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

<Callout type="info">
官网的 uv 下载会访问 GitHub，国内网络可能会出现访问缓慢或失败的情况。可以使用 [国内镜像](https://uv.agentsmirror.com) 进行安装。

```bash
curl -LsSf https://uv.agentsmirror.com/install-cn.sh | sh
```

</Callout>

如果一切顺利，安装过程应该类似于下：

```text
$ curl -LsSf https://uv.agentsmirror.com/install-cn.sh | sh
downloading uv 0.11.30 x86_64-unknown-linux-gnu
installing to /home/user/.local/bin
  uv
  uvx
everything's installed!
$ uv --version
uv 0.11.30 (x86_64-unknown-linux-gnu)
```

<Callout type="info">
Windows 用户推荐使用 [scoop 安装 uv](https://docs.astral.sh/uv/getting-started/installation/#scoop)

如果你的电脑上已经安装了 Python，可以直接使用 `python -m pip install uv` 安装 uv。
</Callout>

## 连接 LLBot

下面举例三种协议的对接方式，选择其中一种使用即可 (本人讨厌 OneBot11, 所以请自行探索 OneBot11 的对接方式)。

## 接入 Satori

<Steps>
<Step>
### 在 LLBot 启用 Satori 协议

在 LLBot 中启用 Satori，可以通过以下任一方式配置：

- **LLBot Desktop**：Bot 配置 → 启用 Satori → 填入配置保存
- **LLBot WebUI**（默认 http://localhost:3080）：启用 Satori → 填入配置保存
- **直接修改配置文件** `data/config_<qq>.json`：

```json5
{
  "satori": {
    "enable": true,  // 是否启用 Satori 协议
    "port": 5600,  // Satori 监听端口
    "token": "your_token", // Satori token
  },
}
```
</Step>

<Step>
### 配置 Entari

Entari 原生支持 Satori 协议，所以无需额外安装适配器，只需要在 Entari 的配置文件中配置[网络项](https://arclet.top/tutorial/entari/#%E5%9F%BA%E7%A1%80%E9%85%8D%E7%BD%AE)即可：

```yaml
basic:
  network:
    - type: ws
      host: localhost
      port: 5600
      token: "your_token"
      path: ""
```

host 和 port 填写 LLBot 的 Satori 服务的地址（如 http://localhost:5600），token 填写 Satori 服务的 token（没有则不填写），即可连接到 LLBot
</Step>
</Steps>

## 接入 Milky

<Steps>
<Step>
### 在 LLBot 启用 Milky 协议

在 LLBot 中启用 Milky，可以通过以下任一方式配置：

- **LLBot Desktop**：Bot 配置 → 启用 Milky → 填入 http 配置保存
- **LLBot WebUI**（默认 http://localhost:3080）：启用 Milky → 填入 http 配置保存
- **直接修改配置文件** `data/config_<qq>.json`：

```json5
{
  "milky": {
    "enable": true,
    "reportSelfMessage": false,
    "http": {  // Milky 的 WS 和 HTTP 实际上是共用一个端口的
      "port": 3010,
      "prefix": "/api", // http api 路径前缀，可为空，默认是/api
      "accessToken": ""
    }
  }
}
```
</Step>

<Step>
### 安装 milky 适配器

使用 `entari adapter add` 命令安装 milky 适配器：

```
$ entari adapter add

 7. QQ                QQ 适配器 (satori-python-adapter-qq)

Prepared 1 package in 621ms
Installed 1 package in 7ms
 + satori-python-adapter-milky==0.5.0
适配器 Milky 已成功添加到配置文件中。
```
</Step>
<Step>
### 配置 Entari

修改 Entari 配置项，参考 [Entari 配置文档](https://arclet.top/tutorial/entari/server.html#%E9%80%82%E9%85%8D%E5%99%A8)。

根据 [milky 适配器](https://arclet.top/tutorial/entari/server.html#milky-%E9%80%82%E9%85%8D%E5%99%A8) 的说明，添加以下配置：

```yaml
adapters:
  - $path: '@milky.main'
    endpoint: "http://localhost:3010/api"
    token: "your_token"
```

注意 **endpoint** 中的端口需要和 LLBot 的 Milky HTTP 端口一致，**token** 需要和 LLBot 配置的 token 一致。
</Step>
</Steps>

连接成功后，Entari 日志会显示 Bot 已连接。
